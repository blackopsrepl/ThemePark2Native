# Controls

Theme Park keeps its original keyboard shortcuts and mouse behavior. The host
maps coordinates through the aspect-correct content rectangle, so window size,
side bars, and fullscreen do not move the DOS pointer relative to the picture.

Click the game to capture the pointer. `Ctrl+F10` or switching to another
application releases it. The Windows arrow is hidden over captured gameplay;
Theme Park continues drawing its own cursor.

`Escape` is delivered to the game, including during the intro. When
`MAIN.EXE` returns to DOS, the native application closes instead of revealing
an emulator menu. `Alt+Enter` toggles borderless fullscreen. `Ctrl+F5` saves a
quick state and `Ctrl+F9` restores it.

## Xbox controller

| Xbox input | Native mapping |
|---|---|
| D-pad | Arrow keys / menu navigation |
| Right stick | Mouse pointer |
| A or right trigger | Left mouse button |
| B or left trigger | Right mouse button |
| X | F |
| Y | O |
| Menu | P / pause |
| View | Escape / back |
| Right shoulder | Enter |
| Left shoulder | Space |

The left stick is intentionally unassigned. The right-stick response uses a
dead zone and nonlinear acceleration for precise icon selection near center.
